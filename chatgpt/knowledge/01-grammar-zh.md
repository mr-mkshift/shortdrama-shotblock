# 중국어 분경조 문법

Dreamina(即梦·Jimeng)·Doubao·Seedance 계열에 넣는 형태다.
블록 명칭은 `【】` 로 감싸고, 순서를 지킨다. 모델이 순서로 우선순위를 읽는다.

아래는 전부 **슬롯 템플릿**이다. `<>` 안은 이번 작품의 값으로 채운다.
슬롯 밖 문장은 문법이 요구하는 뼈대라 그대로 두지만, 슬롯을 비워두거나
참조 자료에 있던 값으로 채우면 남의 작품이 튀어나온다.

## 목차

1. 블록 순서
2. 고정층 템플릿
3. 변동층 템플릿
4. 실사 / 3D 애니 차이
5. 자주 쓰는 표현 대응표

## 2. 고정층 템플릿

### 【全局风格质感】

화면비 → 장르·질감 → 렌더 기준 → 금지 목록 순으로 쓴다. 금지 목록은 반드시 넣는다.

```
【全局风格质感】<화면비>，<장르 질감>，<세계관>，<렌더 스타일>；
<화질 기준 3~5개>；无字幕、无水印、无背景音乐；<반드시 선명해야 할 것>；
本场主要<주 이펙트>贴合道具和动作变化，画面干净。
```

- `<화질 기준>` — 렌더 품질 어휘를 3~5개만 고른다. 예: `电影级CG` `4K高清` `光线追踪` `材质写实逼真` `高对比度明暗层次`. 더 쌓아도 효과가 안 늘고 토큰만 먹는다
- `<반드시 선명해야 할 것>` — 이 작품에서 흐려지면 안 되는 것. 대화극이면 `角色脸部表情与手部动作清晰`, 액션이면 손과 무기, 제품이면 로고와 재질
- `本场主要…` — 이번 회차의 주 이펙트. **회차마다 바뀌는 유일한 칸이다.** 나머지는 시리즈 내내 고정

금지 목록 세 개(`无字幕、无水印、无背景音乐`)는 슬롯이 아니다. 빼면 자막이 그려진다.

### 【光影设计】

```
【光影设计】<색온도>；<주광 각도>主侧光 + <림 각도>轮廓逆光 + <앰비언트 강도>环境补光；
全局深度阴影（深度<값>/软边<값>/距离<값>）；人物面部眼神光；
<주인공 재질>高光×<배수>、<중간 재질>高光×<배수>、<바닥 재질>高光×<배수>；
保持全局曝光正常、人物面部光线均匀、单一光影方向、自然光源色。
```

하이라이트 세 줄이 핵심이다. 어떤 재질을 주인공으로 삼고 배수를 얼마로 벌릴지는
장면 성격에서 나온다 — `lighting-materials.md` 에 장면 유형별 배합이 있다.

마지막 줄 네 조항은 슬롯이 아니다. 특히 `单一光影方向`(단일 광원 방향)이 빠지면
컷마다 광원이 옮겨 다녀서 같은 씬이 다른 시간대처럼 보인다.

### 【输入模式与人物素材绑定】

참조 이미지를 쓸 때만 넣는다.

```
【输入模式与人物素材绑定】
Omni Reference / <N>组参考生成。
@<캐릭터> = image N = <파일명>：作为<캐릭터>唯一身份参考，锁定同一张脸、年龄、
<헤어>、<수염>、<체형>，以及<의상>和<신발>。
@<배경인물> = image N = <파일명>：只负责锁定<시대·복장>，不改变主요인물的脸。
@标签只用于素材调用，不生成为画面文字。
```

마지막 줄을 빼면 모델이 `@태그`를 화면에 글자로 그린다.

### 【CORE GUIDELINES | 最高优先级后缀】

맨 뒤에 붙인다. 이 블록만 영어로 쓴다 — 모델이 최우선 지시로 더 잘 받는다.

담아야 하는 것은 네 가지다. 문장은 이 뜻이 전달되는 선에서 직접 쓴다.

| 조항 | 없으면 |
|---|---|
| 프롬프트를 이탈 없이 따를 것 | 모델이 "더 좋게" 각색한다 |
| BGM 금지, 앰비언트와 생목소리만 | 스톡 배경음악이 깔린다 |
| 대사는 제공된 문구와 정확히 일치, `<언어>`로 완전히 발화 | 말을 줄이거나 지어낸다 |
| 자막 금지 | 화면에 글자가 박힌다 |

```
【CORE GUIDELINES | 最高优先级后缀】
<위 네 조항을 영어 지시문으로. 대사 언어를 명시한다.>
```

대사 언어 칸을 비워두면 모델이 프롬프트 언어를 따라간다. 중국어 프롬프트에
한국어 대사를 넣는 경우가 특히 위험하니 반드시 명시한다.

## 3. 변동층 템플릿

### 씬 헤더

장소 → 시간 → 실내외 → 근/중/원경 배치. 인물마다 참조 태그를 붙인다.

```
场景：<장소>[@参考图N]<실외/실내>，<日/夜>，<外/内>；
画面近景，<인물A>[@参考图1]<상태와 위치>；
中景，<인물B>[@参考图2]<상태>，<인물C>[@参考图3]<상태>；
<광원 상태>。
```

### 등장 목록

```
角色：<인물A>[@参考图1]、<인물B>[@参考图2]
背景低清角色：<인물C>[@参考图3]（<위치>，不参与清晰主体表演）
物品：<소도구>
【禁止出现任何未在此处标注的角色或者角色名称任何的代称、场景、道具元素】
```

배경 인물을 `背景低清角色` 로 따로 빼는 게 중요하다. 안 그러면 모델이 배경 인물에도 주연급 디테일을 쏟아 리롤 확률이 올라간다.

### 컷

```
镜头N | <초>秒 | <근경/중경/클로즈업>/<앵글>（<상태>）
<인물>[@参考图N]<액션 1~2줄. 서술형. 형용사 최소>
【配音指令：<인물>[@参考图N] | 状态（<상태>） | 语气（<톤/속도/문말>）：
"<대사 원문>"】
取景：<들어오는 구역과 위치>；<안 들어오는 것>不入画。背景<虚化 정도>（f/<값>）。
本镜头仅展示以上内容，禁止添加任何未提及的人物、物体、特效或背景
```

대사 없는 컷은 `【配音指令：无】`.

`取景` 은 배경이 있는 모든 컷에 붙인다. 없으면 근경에서 모델이 배경 전체를 우겨넣으려 화각을 뒤로 뺀다.
**안 들어오는 것을 명시적으로 적는다.** 설계법은 `scene-space.md`.

액션에 발화 싱크를 걸 때:

```
说"<단어1>"时<동작1>，说"<단어2>"时<동작2>，说"<단어3>"时<동작3>。
```

### 종료 상태

```
分镜组结尾固定画面主体与状态：<인물A>[@参考图1]<상태>；<인물B>[@参考图2]<상태>；
<인물C>[@参考图3]<상태>。
```

### 인계

```
【尾帧与S<다음화번호>衔接】
<렌즈>mm<인물>反应近景，<소도구 위치>，<표정>，目光看着<대상>，嘴唇刚要张开。
S<다음화번호>从<인물>回答："<다음 화 첫 대사>"开始。
```

## 4. 실사 / 3D 애니 차이

| | 실사 | 3D 애니 |
|---|---|---|
| 스타일 블록 | `真人电影实拍`, `自然皮肤`, `独立湿发丝`, `粗麻衣物` | `玄幻3D国漫短剧质感`, `3D动漫风`, `Unreal Engine 5写实风格` |
| 렌즈 표기 | `35mm低机位`, `50mm中近景` 처럼 실제 초점거리 | 화각만 (`近景/平视`) — 초점거리는 잘 안 먹는다 |
| 추가 잠금 | `【真人风格锁定】` — 배우 국적·피부·젖은 머리카락 질감 | `【表演与节奏锁定】` — 동작 사슬과 반응 층위 |
| 연속성 | `【人物与状态连续性】` — 인물별 image 번호 못 박기 | 참조도 태그로 충분 |

실사에서 `【人物与状态连续性】` 은 빼면 얼굴이 흔들린다:

```
【人物与状态连续性】
<인물A>只认image 1，<인물B>只认image 2，<배경인물>只认image 3。
<인물A>保持<고정 의상>，不变成<흔한 오답>；
<인물B>的<헤어>、<수염>、<의상>、<신발>与<소도구>全程一致。
人物在低头、抬头、说话和快速切镜时保持各自同一张脸、年龄、肤色、发型、身形与服装。
<환경 연속 요소>连续。
```

`不变成<흔한 오답>` 이 실전에서 잘 듣는다. 몇 번 뽑아보면 모델이 늘 같은 방향으로 틀린다 — 특정 색으로 돌아가거나, 소매 길이가 자꾸 바뀌거나, 안경이 사라지거나. 그 방향을 알아낸 뒤 **틀리는 쪽을 직접 지목**한다. 처음엔 비워두고 리롤하면서 채운다.

## 6. 【配音音色表】 — 고정층 블록 (필수)

음색과 성격은 **인물 상수**라 컷에 적지 않는다. 컷의 `【配音指令】` 에는 状态와 语气 두 칸만 쓴다.
같은 상수가 컷마다 반복되면 반드시 어긋난다. 대신 고정층에 이 블록을 한 번 둔다.

위치: 【人物与状态连续性】 뒤, 첫 분경조 앞.

```
【配音音色表】
@<인물A>：<음색 한 구절>；<성격 한 구절>。
@<인물B>：<음색 한 구절>；<성격 한 구절>。
音色与性格仅在此声明一次，各镜头只写状态与语气。
```

마지막 줄을 빼면 모델이 컷마다 음색을 새로 정한다.

## 7. 【场景空间锁定】·【景深分级】·取景

배경 구역 분할, 컷별 取景, 심도 등급, 발광 배경 처리는 `scene-space.md` 에 전문이 있다.
블록 위치만 여기 적는다.

- 【场景空间锁定】 — 【人物与状态连续性】 뒤, 【配音音色表】 앞
- 【景深分级】 — 【光影设计】 안에 접거나 그 바로 뒤에 독립 블록으로
- 取景 — 각 컷의 액션 아래, `本镜头仅展示…` 위
