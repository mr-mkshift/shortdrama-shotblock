# 프로젝트 카드 — 고정층을 세션 밖으로 꺼내기

## 왜 필요한가

고정층은 프로젝트 상수인데, 대화가 끝나면 사라진다.
다음 회차를 다른 세션에서 시작하거나 다른 에이전트(Codex·Custom GPT)에 물리면,
그쪽은 이 작품에 대해 아무것도 모른 채 스킬의 **기본값**으로 되돌아간다.

결과는 늘 같다 — 문법은 맞는데 방향이 다른 결과물이 나온다.
스킬이 잘못된 게 아니라 **재료가 안 넘어간 것**이다.

프로젝트 카드가 그 그릇이다. 프롬프트가 아니라 **입력**이다.
컴파일러에게 "이번 작품의 상수는 이거다"라고 건네는 재료다.

## 우선순위

**카드에 적힌 값은 이 스킬의 일반 규칙을 덮어쓴다.**

스킬은 여러 작품에 두루 맞는 기본값을 담고 있고, 카드는 이 작품에서 실제로 통한 값을 담는다.
둘이 충돌하면 카드가 이긴다. 그래서 `이 작품의 예외` 칸이 카드에서 가장 값나가는 자리다.

컴파일 절차 2단계에서 카드부터 확인하는 이유가 이것이다.

## 카드 형식

```
[프로젝트 카드]

작품            <이름 / 회차>
타깃·언어       <Dreamina·Seedance → 중국어 / Veo·Sora → 영어>
클립 규격       <총 길이> / <단일 생성 or N분할> / <툴의 최소·최대 길이, 프리셋 여부>
화면비          <1:1 / 9:16 / 16:9>

참조도
  @<태그> = image <N> = <파일명>
      잠그는 것: <얼굴·나이·헤어·체형·의상·신발>
      안 잠그는 것: <표정·입모양·얼굴 방향·머리 각도>
  (배경 상태가 도중에 바뀌면 상태별로 장을 나눈다 — scene-space.md 참고)

공간            <구역 분할 A/B/C + 각 구역 내용>
                <인물이 어느 구역 앞에 서는가>
                <반드시 나와야 하는 고정 陈设>

조명            주광원 <무엇>
                재질 상대비 <주인공 ×1.5 / 중간 ×0.5 / 바닥 ×0.3>
                심도 등급 <중경 f/N / 중근경 f/N / 근경 f/N / 클로즈업 f/N>

음색표          @<태그>: <음색 한 구절> / <성격 한 구절>

화면 내 문자    생성에 넣는 것: <참조도에 박혀 있어 복제 가능한 글자>
                편집 합성할 것: <자막·로고·오버레이·엔드카드>

이 작품의 예외  <스킬 기본값을 덮어쓰는 결정과 그 이유>

미해결          <아직 안 정한 것 / 리롤하며 채울 칸>
```

## 채우는 법

### 처음 만들 때

첫 컴파일을 마친 직후에 만든다. 그때가 값이 다 모여 있는 시점이다.
컴파일 전에 만들려 들면 빈칸투성이가 되고, 빈칸은 결국 추측으로 채워진다.

### 갱신할 때

리롤하면서 알아낸 것을 그때그때 `이 작품의 예외` 와 `미해결` 에 적는다.
특히 **모델이 반복해서 틀리는 방향**은 알아내는 즉시 적는다 —
그게 다음 회차의 리롤을 가장 많이 줄인다.

### 넘길 때

새 세션·다른 에이전트의 첫 메시지에 카드 전문을 붙인다.
그 뒤에 이번 회차의 컷 재료(대사·장소·동선)만 주면 된다.

## 카드에 넣지 않는 것

컷 변수는 넣지 않는다. 넣으면 회차마다 덮어써야 해서 관리가 두 배가 된다.

- 상태·어조·표정·자세
- 대사
- 컷 길이 배분
- 그 컷에서만 드는 소품
- 취경

기준은 고정층/변동층과 같다 — **2화 뒤에도 같은 값인가.**

## 왜 `이 작품의 예외` 가 중요한가

이 스킬의 규칙은 대부분의 경우에 맞지만, 전부 맞는 건 아니다.
작품마다 툴·소재·클라이언트 사정으로 뒤집히는 항목이 생긴다.

예외를 적어두지 않으면 다음 세션이 스킬 기본값으로 되돌아가고,
사용자는 같은 교정을 처음부터 다시 하게 된다. 그게 가장 비싼 낭비다.

예외 칸에 적을 만한 것들:

- 스킬이 금지한 것을 이번엔 허용하기로 한 결정 (그리고 그게 통한 이유)
- 툴 버전 때문에 달라진 길이·분할 규칙
- 참조도를 상태별로 나눈 구조
- 기본 심도 등급을 바꾼 이유
- 캐릭터시트 훼손을 생략했다면 그 대신 넣은 텍스트 방어책

각 줄은 **결정 + 이유** 두 조각으로 적는다.
이유가 없으면 다음 사람이 그 예외를 지워버린다.
