# 캐릭터 바이블 — 상수 관리와 시트 제작

캐릭터에 붙박이인 값들을 한 곳에 모아두는 문서다.
컷 프롬프트는 여기를 참조만 하고, 값을 다시 쓰지 않는다.
같은 값이 두 곳에 있으면 반드시 어긋난다 — 그게 80편짜리 시리즈에서 얼굴이 흔들리는 경로다.

## 1. 상수표 스키마

캐릭터마다 이 여덟 칸을 채운다.

| 칸 | 무엇을 적나 | 왜 상수인가 |
|---|---|---|
| 태그 | 프롬프트에서 부를 이름 | 소재 호출용 핸들 |
| 참조 이미지 | `image N = <파일명>` | 정체성의 단일 출처 |
| 고정 외형 | 나이대, 헤어, 체형, 얼굴 특징 | 참조 이미지가 잠그는 것 |
| 고정 의상 | 상의·하의·신발·액세서리 | 화마다 바뀌면 시리즈가 아니다 |
| 흔한 오답 | 모델이 반복해서 틀리는 방향 | 지목하면 대부분 막힌다 |
| 음색 | 음역·질감을 한 구절로 | 목소리는 인물에 붙박이 |
| 성격 | 말투의 바닥값 | 연기의 기본 상태 |
| 소도구 | 인물과 늘 함께 다니는 것만 | 씬 소품은 여기 안 넣는다 |

**흔한 오답 칸**이 실전에서 제일 값나간다. 몇 번 뽑아보면 모델이 늘 같은 방향으로 틀린다 —
특정 색으로 돌아가거나, 소매 길이가 바뀌거나, 안경이 사라지거나.
그 방향을 알아낸 뒤 `不变成<오답>` / `does not shift to <오답>` 으로 박는다.
처음엔 비워두고 리롤하면서 채워 나가는 칸이다.

## 2. 상수에 넣지 않는 것

이건 컷 변수다. 바이블에 넣으면 컷마다 덮어써야 해서 관리가 두 배가 된다.

- 상태 (그 컷에서 인물이 처한 감정 국면)
- 어조 (속도·높낮이·문말 처리)
- 자세와 화면 내 위치
- 표정
- 대사
- 그 씬에서만 드는 소품

기준은 하나다. **2화 뒤에도 같은 값인가.**

## 3. 캐릭터시트 훼손

### 왜 훼손하나

영상 모델은 참조 이미지의 얼굴을 **픽셀 그대로 복사**하려 든다.
그러면 표정이 안 바뀌고, 각도가 안 돌아가고, 클로즈업이 마네킹처럼 나온다.

얼굴을 격자로 덮으면 모델은 "이 얼굴을 베껴라"가 아니라
"이 정체성 단서에 맞는 얼굴을 그려라"로 읽는다. 표정과 각도가 살아난다.

### 무엇을 남기고 무엇을 덮나

| 남긴다 | 덮는다 |
|---|---|
| 헤어스타일 전체 (묶은 모양·앞머리·잔머리) | 눈·코·입 |
| 얼굴 윤곽선과 턱선 | 눈썹 안쪽 |
| 귀 | 피부결·점·주름 |
| 목·어깨 라인 | 홍채 색 |
| 의상 전체 | |
| 체형·비율 | |

윤곽과 헤어는 남겨야 한다. 그게 없으면 정체성 자체가 안 전달된다.
**정체성 단서는 남기고 픽셀 복사만 막는 것**이 목표다.

### 격자 사양

- 사선 교차 격자(crosshatch). 가로세로 격자는 얼굴 구조와 헷갈린다
- 선 굵기: 얼굴 폭의 1.5~2.5%
- 간격: 선 굵기의 3~5배
- 색: 배경과 대비되는 진한 색 (남색·검정). 반투명 아님, **불투명**
- 덮는 비율: 얼굴 영역의 55~70%. 90%를 넘기면 정체성까지 사라진다

### 시트 구성

한 캐릭터당 이렇게 낸다:

```
1행   얼굴 정면 / 3/4 / 뒤통수     ← 정면·3/4만 훼손, 뒤통수는 그대로
2행   전신 정면 / 측면 / 뒷면      ← 얼굴이 작으므로 훼손 불필요
별도  클로즈업 크롭 (눈가·입가·손·발)  ← 얼굴 크롭은 반드시 훼손
```

**클로즈업 크롭도 훼손한다.** 여기를 빼먹으면 클로즈업 컷만 레퍼런스를 그대로 베껴 온다.
전신만 훼손하고 클로즈업을 그대로 두는 게 흔한 실수다.

뒤통수와 전신은 훼손하지 않는다. 얼굴이 안 보이거나 작아서 복사 위험이 없고,
오히려 헤어와 실루엣 정보를 온전히 줘야 한다.

### 배경 인물 시트

주연과 다르게 만든다.

```
@배경인물 = 시대 복장과 실루엣만 잠근다. 얼굴은 아예 안 준다.
```

프롬프트에도 `背景低清角色` / `low detail, non-performing` 으로 명시한다.
안 그러면 모델이 배경 인물에도 주연급 디테일을 쏟아서, 주연이 상대적으로 죽고 리롤 확률이 오른다.

## 4. 바이블 출력 형식

처음 만들 때와 고칠 때만 낸다. 매 컷 재출력하지 않는다.

칸의 모양만 아래와 같고, 값은 **사용자가 이번 작품에 대해 말한 것**으로 채운다.
참조로 받은 다른 작품의 캐릭터를 여기 옮겨 적으면 그 인물이 결과물 전체에 번진다.

```
[캐릭터 바이블]

@<태그>  image <N> = <파일명>
  외형   <나이대>, <헤어>, <체형>, <얼굴 특징>
  의상   <상의>, <하의>, <신발>, <액세서리>
  오답   <반복해서 틀리는 방향 — 처음엔 비움>
  음색   <음역·질감 한 구절>
  성격   <말투의 바닥값>
  소도구 <늘 함께 다니는 것 / 없으면 "없음">

@<배경인물 태그>  image <N> = <파일명>
  용도   <시대·복장·실루엣만>. 얼굴 없음. 배경 저해상 처리
```

주연 캐릭터는 여덟 칸을 다 채우고, 배경 인물은 `용도` 한 줄이면 된다.
