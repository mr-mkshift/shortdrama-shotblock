# 배경 구역과 취경 — 화각이 바뀌어도 공간이 안 흔들리게

## 왜 참조도 한 장으로 안 되는가

배경 참조도는 재질과 구도를 같이 잠근다. 재질만 잠그고 싶은데 구도까지 따라온다.

그래서 근경으로 들어가면 모델이 참조도의 레이아웃을 재현하려고 두 가지 중 하나를 한다 —
화각을 뒤로 빼서 배경을 다 넣거나, 프레임 밖에 있어야 할 요소를 억지로 끌어온다.
연속성 조항에 "요소 A와 B가 연속"이라고 써두면 이게 확정된다. 클로즈업에도 A와 B가 들어온다.

역할을 셋으로 갈라놓으면 풀린다.

| 무엇이 | 무엇을 잠그나 | 어디에 쓰나 |
|---|---|---|
| 배경 참조도 | 재질·색·기물 | 소재 바인딩 블록 |
| 공간 잠금 | 구역의 좌우 순서와 높이, 인물이 서는 자리 | 고정층 |
| 취경 | 이번 컷에 들어오는 구역과 흐림 정도 | 컷마다 한 줄 |

---

## 1. 공간 잠금 블록

배경을 카메라 시점 기준 2~4개 구역으로 나눈다. 다섯을 넘으면 관계가 흐려진다 —
배경이 복잡하면 더 쪼개지 말고 뭉친다.

구역마다 이름·위치·내용을 준다. 좌우 순서와 높이는 시리즈 내내 안 바뀐다.
인물이 어느 구역 앞에 서는지도 여기서 정한다. 이게 정해지면 단독 컷의 배경이 자동으로 결정된다.

마지막 두 줄이 핵심이다. 빼면 이 블록이 오히려 "매 컷에 전부 나와야 한다"로 읽힌다.

### 중국어

```
【场景空间锁定】
<장소>为固定空间，方位以摄影机视角描述。
<배경 전체의 형태 한 줄>。
分<N>区，左右顺序全场不变：
A区（<위치>）<이름>——<내용>。
B区（<위치>）<이름>——<내용>。
C区（<위치>）<이름>——<내용>。
<바닥·천장·부속 요소>。
<인물A>站在<구역> 前，<인물B>站在<구역> 前；<인물 간 간격과 화면 좌우>。
镜头只在此空间内取景，不新增<흔히 지어내는 것들>。
每个镜头只呈现该镜头【取景】一行指定的区域；
未进入取景范围的元素不得为了"连续"而强行塞入画面。

【景深分级】
中景 f/<값>，中近景 f/<값>，近景 f/<값>，特写 f/<값>；同级虚化程度全场一致。
```

### 영어

```
SPACE LOCK — <장소> is a fixed set, described from the camera's viewpoint.
<배경 전체의 형태 한 줄>.
<N> zones, left-to-right order fixed for the whole series:
Zone A (<위치>) <이름> — <내용>.
Zone B (<위치>) <이름> — <내용>.
Zone C (<위치>) <이름> — <내용>.
<바닥·천장·부속 요소>.
<인물A> stands in front of <구역>, <인물B> in front of <구역>. <간격과 화면 좌우>.
Frame only inside this set. Add no <흔히 지어내는 것들>.
Each shot shows only the zones named in that shot's FRAMING line.
Elements outside the framing must not be forced in for the sake of continuity.

DEPTH TIERS — medium f/<값>, medium close f/<값>, close f/<값>, extreme close f/<값>.
Blur within a tier is identical throughout.
```

심도를 등급으로 고정하는 게 중요하다. 컷마다 흐림을 새로 정하면 같은 화각인데 배경 거리가 달라 보인다.

## 2. 취경 — 화각이 좁아질수록 배경은 색면이 된다

원경·중경에서는 배경 요소를 **이름**으로 지정한다.
근경 이하에서는 **색면과 발광면의 위치**로 지정한다.

배경이 아웃포커스로 뭉개지는 구간에서 디테일을 요구하면,
모델이 배경을 다시 그리려다 공간 구조 자체를 바꾼다. 이게 근경 리롤의 대부분이다.

| 화각 | 배경을 어떻게 쓰나 | 무엇까지 보이나 |
|---|---|---|
| 중경 | 구역 이름 + 프레임 내 위치 | 구역 경계, 내부 형태 |
| 중근경 | 구역 2개 정도만 | 색층은 남고 디테일은 사라진다 |
| 근경 | 색면 1~2개의 위치와 화면 점유 비율 | 식별 가능한 물체 없음 |
| 클로즈업 | 단일 색면 + 발광 번짐 한 점 | 윤곽 없음 |

컷마다 한 줄로 쓴다. 씬 헤더 아래, 액션 위.

```
取景：<들어오는 구역과 프레임 내 위치>；<안 들어오는 것 열거>。
背景<虚化 정도>（f/<값>），<이 화각에서 남는 것과 사라지는 것>。

FRAMING — <들어오는 구역과 위치>. <안 들어오는 것> out of frame.
Background <blur 정도> (f/<값>). <남는 것과 사라지는 것>.
```

**안 들어오는 것을 명시적으로 적는다.** 이게 빠지면 모델이 습관적으로 다 넣는다.

### 근경 이하에서는 배경 참조도를 호출하지 않는다

씬 헤더에서 배경 참조 태그를 뺀다.
참조도가 얻는 것(재질·색)보다 잃는 것(구도 재현 시도)이 크다.
그 컷의 배경은 취경 한 줄이면 충분하다.

## 3. 연속성 조항 고쳐 쓰기

"요소 A·B·C가 연속"은 "매 컷에 A·B·C가 다 나온다"로 읽힌다. 이렇게 쓴다.

```
<요소들>的相对位置与材质全场连续，
但仅在该镜头取景范围内呈现；连续性不等于每个镜头都要出现全部元素。

<요소들> stay continuous in relative position and material,
but appear only within that shot's framing. Continuity is not a roll call.
```

## 4. 배경이 발광할 때

LED월·모니터·창·네온처럼 배경이 스스로 빛나면 그건 배경이 아니라 **광원**이다.
그대로 두면 인물이 역광으로 눌린다.

- 카메라 측 정면 보조광을 **얼굴 주광**으로 따로 세운다
- 발광면을 하이라이트 상대비의 주인공 자리에 놓는다 (`lighting-materials.md`)
- 배경 색이 바뀌는 컷에서는 인물 윤곽에 떨어지는 색 스필도 적는다
- 단, **얼굴 피부톤은 불변**으로 못 박는다. 안 그러면 배경이 붉어질 때 얼굴까지 붉어진다

```
主光源为<발광면>自发光——大面积柔光，来自人物正后方偏上，形成轮廓逆光与发梢边缘光。
摄影机侧另置一盏正面柔光箱作为面部主光，<색온도>K，确保面部曝光不被逆光压暗。
<발광면>的色彩变化只在人物轮廓侧形成轻微色溢，不改变面部肤色。

The <발광면>'s own emission is the key: a large soft source behind and slightly above
the performers, giving rim light and edge light on the hair.
A frontal softbox on the camera side carries the face at <색온도>K,
so the backlight does not crush facial exposure.
Colour shifts on the <발광면> spill onto the performers' contours only,
never onto facial skin tone.
```

### 발광 상태가 변하는 컷

배경 발광이 튀어야 하면 **램프(점진 상승)로 쓰지 말고 점등으로 쓴다.**
점진 상승은 편집에서 얹는 그래픽과 어긋난다 — 빛이 먼저 밝아지고 글자가 늦게 뜬다.

점등 시점은 대사의 특정 단어 프레임에 건다. 그리고 세 가지를 적는다.

1. 어느 단어의 첫 프레임에 켜지는가
2. 오버슈트 후 안정까지의 시간
3. 그 뒤로는 깜빡임·호흡 없이 고정이라는 것

```
幕墙状态：<구역>在<인물>说出"<단어>"的第一帧瞬间点亮——<변화 내용>；
点亮瞬间<과장 요소>轻微过冲，<초>秒内回落至稳定，此后恒定，不闪烁、不呼吸。
同一帧<인물><부위>的色溢跃升一档，此后保持恒定；面部肤色不变。
```

3번을 빼면 모델이 발광면을 계속 미세하게 맥동시킨다.

## 5. 화면 내 문자 — 참조도에 없는 글자

참조도에 없는 글자를 맨땅에서 그리라고 하면 깨진다. 한글은 특히 그렇다.
컷마다 글자가 달라지면 배경 전체가 재생성되면서 다른 구역까지 흔들린다.

이 경우엔 **문자를 생성에서 빼고 편집 합성으로 돌린다.** 그 자리를 색면으로만 지정한다.

```
<구역>为图形位，生成中不出现任何文字，保持为干净的<색> 面。
Zone <N> is a graphic slot. Generate it as a clean <색> field with no lettering of any kind.
```

다만 **발광 변화 자체는 생성에 남긴다.** 인물에 떨어지는 빛과 반사가 영상에 있어야
나중에 얹는 글자가 붙는다. 빛은 생성, 글자는 편집이다.

편집 순서도 정해져 있다 — 생성 클립을 먼저 받고, 실제로 점등된 프레임을 찾아
거기에 키프레임을 맞춘다. 반대로 하면 안 된다. 생성물의 점등 프레임은 뽑을 때마다 흔들린다.

**참조도에 이미 글자가 박혀 있다면 얘기가 다르다.** 그때는 생성에 넣는다 — 7장을 본다.

## 6. 배경 상태가 도중에 바뀔 때 — 참조도를 상태별로 나눈다

배경 화면(LED월·모니터·간판)의 내용이 회차 중간에 바뀌면,
참조도 한 장으로 두 상태를 다 표현하려 들지 않는다. **상태마다 한 장씩 만든다.**

```
@Background       = image 3 = <변화 전 파일명>
@Background_After = image 4 = <변화 후 파일명>
    image 3과 같은 세트·같은 陈设, 바뀌는 구역만 다르다. 나머지는 픽셀 단위로 동일해야 한다
```

두 장이 세트 나머지에서 어긋나면 전환 컷에서 배경 전체가 튄다.
같은 소스에서 해당 구역만 고쳐 뽑는다.

### 컷마다 어느 장을 쓰는지 명시한다

```
本片仅使用 image 1、image 2、image 3。不调用 image 4。
本片<구역>全程为<변화 전 상태>，不显示<변화 후 요소>。
```

`不调用` 을 안 적으면, 참조도가 걸려 있다는 것만으로 변화 후 상태가 미리 나타난다.
변화 전 컷에서는 반드시 두 줄로 막는다.

### 전환은 한 컷 안에서 일어난다

전환 컷에서만 두 장을 다 물리고, 시점을 명시한다.

```
0.0—<t>秒：<구역>为image 3的状态——<내용>。
<t>秒：切换为image 4的状态——<내용>，<팝인/점등 사양>。
<t+α>—<끝>秒：完全静止，不闪烁、不呼吸。
```

### 화면 가득 잡는 인서트 컷을 하나 만든다

배경 화면의 변화가 이 회차의 핵심이면, 인물 없이 **그 화면만 잡는 컷**을 따로 둔다.

- 글자가 화면 가득 커져서 렌더 정확도가 올라간다
- 전환 타이밍이 그 컷 안에 갇혀 다른 컷이 안 흔들린다
- 인물 컷의 배경은 계속 아웃포커스로 둘 수 있다

분할 생성이면 이 인서트를 클립 경계로 삼는다.
**클립 경계를 배경 상태가 바뀌는 지점에 맞추면** 참조도가 클립 안에서만 갈려서
리롤이 한 클립에 갇힌다.

## 7. 배경 화면 안의 문자

`SKILL.md` 의 "화면 내 문자" 항목을 여기서 갈라 쓴다.

| 글자의 출처 | 어떻게 | 왜 |
|---|---|---|
| 참조도에 이미 박혀 있다 | **생성에 넣는다.** 逐字 복제하라고 지시 | 복제는 안정적이다. 새로 그리는 것과 난이도가 다르다 |
| 참조도에 없다 | 참조도를 새로 만들어 박아 넣거나, 편집 합성 | 맨땅에서 그리면 깨진다 |
| 프레임 위에 얹는 것 | 언제나 편집 합성 | 자막·로고·고지는 세트가 아니다 |

생성에 넣을 때는 **자막과 구분**해줘야 한다. 스타일 블록의 `无字幕` 이 세트 안의 글자까지 죽인다.

```
无字幕、无水印——但<배경 화면>内的画面文字属于场景内容而非字幕，必须保留。
```

그리고 화이트리스트를 건다. 안 걸면 참조도에 없는 글자까지 지어낸다.

```
<배경 화면>上只出现<글자 A>与<글자 B>这些文字内容；
除此之外画面任何位置不得出现其他文字、数字、小字、注记、标识或水印。
```

**빛은 생성, 글자는 편집** 이라는 절충도 가능하다.
글자를 합성할 계획이라도 그 자리의 **발광 변화는 생성에 남긴다** —
인물에 떨어지는 빛과 반사가 영상에 있어야 나중에 얹는 글자가 붙는다.

## 안 하는 것

- **구역 다섯 개 이상** — 관계가 흐려져 아무 구역도 안 잠긴다
- **근경 컷에 배경 참조도 호출** — 구도를 재현하려 든다
- **취경 없이 컷 쓰기** — 모델이 배경 전체를 우겨넣으려 화각을 뒤로 뺀다
- **안 들어오는 것을 안 적기** — 적힌 것만 넣으라고 해도 습관적으로 다 넣는다
- **컷마다 다른 심도** — 같은 화각인데 배경 거리가 달라 보인다
- **참조도에 없는 문자를 생성에 요구** — 깨진다. 참조도에 박아 넣거나 편집 합성으로 돌린다
- **상태가 바뀌는 배경을 참조도 한 장으로 처리** — 변화 전 컷에 변화 후 상태가 미리 새어 나온다
- **`无字幕` 만 쓰고 세트 안의 글자를 구분 안 하기** — 파사드·모니터의 글자까지 같이 죽는다
